Исследовательский центр NZTmedicine открыл публичный доступ к своей песочнице для анализа медицинских метрик.

Система работает просто: вы загружаете свои файлы в рабочую директорию, а затем сервер запускает скрипт analyzer.py, который с помощью стандартной библиотеки random обсчитывает ваши данные.

Администратор уверен, что система безопасна, ведь вы не можете изменить исходный код самого analyzer.py. Но он забыл одну критическую деталь о том, как интерпретатор ищет свои инструменты.

Сможешь заставить их сервер прочитать файл /flag.txt?
