# CTF Labs: Описание заданий NZTmedicine

В данном файле собраны описания всех заданий формата Capture The Flag (CTF), объединенных историей теневой фармакологической корпорации **NZTmedicine**.

## 1. OSINT — Прозрачная статистика
* **Категория:** OSINT
* **Легенда:** Корпорация заявляет о строжайшей защите данных клинических испытаний, однако аналитики случайно оставили рабочий статистический отчет в открытом доступе. Поисковые системы уже успели его проиндексировать.
* **Задача:** Найти этот документ в сети и получить скрытую информацию (флаг). 
* **Особенности:** Взлом не требуется. Необходимо использовать продвинутые поисковые запросы (Google Dorks). Известно, что сайт располагается на хостинге `github.io`.

## 2. Web — Громкий сбой
* **Категория:** Web
* **Легенда:** IT-отдел выкатил новый портал для проверки статуса партнеров. Разработчик утверждает, что бэкенд "пуленепробиваемый" и система никогда не выдаст наружу отладочную информацию.
* **Задача:** Найти способ сломать логику сервера, чтобы он выдал ошибку и раскрыл конфиденциальные данные (флаг).
* **Особенности / Уязвимость:** Скрипт (PHP) ожидает получить от пользователя строку (ID). Если через инструменты разработчика (F12) модифицировать запрос и передать неожиданный тип данных (например, массив), внутренняя функция вызовет необработанное исключение и выведет флаг.

## 3. OSINT — Наследие TitorJohn (TICKET-8812)
* **Категория:** OSINT / Threat Intelligence
* **Легенда:** Ведущий аналитик SOC под псевдонимом TitorJohn расследовал подозрительную сетевую активность. Он построил граф расследования на публичной платформе Threat Intelligence, после чего перестал выходить на связь.
* **Задача:** Найти граф расследования TitorJohn'а по стартовому артефакту дроппера. Вычислить истинный C2-сервер (командный центр), маскирующийся под системный сервис, и достать оттуда флаг.
* **Особенности:** В качестве зацепки дается хэш артефакта (SHA-256: `6022be5e9ae7fb483c3542e11518d34bcb0c7e14b8a70d92a484a3feee9276bb`). Искать нужно на ресурсах, где проверяют файлы на вирусы и строят графы связей (например, VirusTotal), обращая внимание на комментарии сообщества.

## 4. Web / Scripting — Фальшивая наука (Python Hijacking)
* **Категория:** Web / Scripting (CWE-427)
* **Легенда:** Открыт публичный доступ к песочнице для анализа медицинских данных. Пользователи загружают файлы, а сервер запускает системный скрипт `analyzer.py`, использующий стандартную библиотеку Python (`random` или `math`) для подсчетов. Администратор считает систему безопасной, так как исходный код `analyzer.py` защищен от изменений.
* **Задача:** Заставить сервер выполнить произвольный код и прочитать содержимое файла `flag.txt`.
* **Особенности / Уязвимость:** Уязвимость подмены модулей (Python Module Hijacking - CWE-427). Поскольку пользовательские файлы попадают в ту же папку, откуда запускается скрипт, можно загрузить свой вредоносный файл с именем стандартной библиотеки (например, `random.py` или `math.py`). Интерпретатор Python при импорте в первую очередь найдет локальный файл пользователя, что приведет к выполнению заложенного в него вредоносного кода.
